## 页面详设-{端}.md 模板（`docs/05-页面/`，逐页设计 SSOT）

> 每端一份（web / h5 / …）；上游 = 页面设计.md 路由表 + DESIGN.md token；下游 = 前端实现与页面测试。**硬阻断/错误码的前端呈现口径在此定死**（原文 + 可操作文案 + 禁现的选项），防实现漂移；验证锚点（GT）的 UI 落点逐页标注。

```markdown
# 页面详设（<端>）
> 头部字段表 + 页数声明（与路由表数一致，防孤儿路由）

## 1. 第一性原理推导
<公理（本端用户是谁/核心任务/约束）→ 设计决策（为什么页面长这样），3~7 条>

## 2. 通用框架（每页都遵守）
<页头（标题+主操作）；筛选条；抽屉 vs 整页判定线（什么进抽屉什么开整页）；表格规范（密度/列宽/金额对齐/数字等宽）；权限与脱敏呈现；状态语义与硬阻断呈现（错误码原文+可操作文案，禁两可）；四态模板（空/加载/错误/无权限——每页必备）>

## 3. 原型与布局
### 3.1 布局原则与断点
<间距阶/内容最大宽/断点表；引用 DESIGN.md 不复制壳数值>
### 3.2 逐页布局矩阵
<路由表一行不落：路由｜布局原型｜区域构成｜断点行为｜滚动归属｜吸底/吸顶｜四态布局；完整模板见「页面布局稿模板」>
### 3.3 原型骨架
<P1–Pn 原型编号：一类页面一个骨架（列表/表单/详情/看板），文字线框描述；复杂页补 ASCII 线框或截图；**只有原型骨架不算布局稿**>

## 4. 逐页详设（按路由表逐页）
<每页：区块构成 | 数据来源（端点/契约锚点）| 交互与状态 | 硬阻断落点（错误码+文案）| 角色差异；GT 锚点页重点标注前端验收要点>

## 5. 组件清单
<复用组件（shared/）与业务组件（features/<域>/）分列，与前端工程化目录约定对齐；每组件一行：名称|用途|引用页面>

## 6. 待拍板 / 待补
<提案列给用户（图表库/图标体系/多语言文案清单等），定稿销项>

## 7. 联动义务
<改页面 → 本文 + 页面设计路由表；改视觉 token → DESIGN.md；改硬阻断文案 → 前端层级规范条款；新增组件 → 本文清单 + 前端工程化>
```
