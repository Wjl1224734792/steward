## 页面布局稿模板（`docs/05-页面/`，逐页布局 SSOT；可并入详设 §3）

> Steward 适配：布局稿的验收脚本交给 browser-tester；证据写 `browser-evidence.json`（`visual: unverified` 表示视觉未验证）。

> 定位：把「每页怎么摆」写成可落地的布局契约——区域、栅格、断点、四态、滚动归属。**只有 P1–Pn 模式骨架不算布局稿**；壳/滚动/token 引用 DESIGN.md 不复制数值。小项目并入详设 §3；页面多或跨端时独立成册。

```markdown
# 页面布局（<端>）
> 头部字段表：上游 = 页面设计.md 路由表 + DESIGN.md 布局框架节 ｜ 下游 = 页面详设 + 前端实现 + 视觉回归 ｜ 页数声明（与路由表一致）
> 约束：壳结构/滚动主权/token 以 DESIGN.md 为准，本文只写页面内布局，不复制壳数值

## 1. 布局原则
<本端栅格与间距基线（引用 DESIGN.md 间距阶）、内容最大宽、密度取向、断点定义；列表/表单/详情/看板各一条>

## 2. 断点与栅格
| 断点 | 宽度 | 列数 | 边距 | gutter | 典型变化 |
|---|---|---|---|---|---|
| <sm/md/lg/xl> | <≥/＜ px> | <n> | <px> | <px> | <卡片列数/筛选条折叠/表格横向滚动> |

## 3. 逐页布局矩阵（路由表一行不落）
| 路由 | 布局原型 | 区域构成（上→下/左→右） | 断点行为 | 滚动归属 | 吸底/吸顶 | 四态布局 |
|---|---|---|---|---|---|---|
| <路径> | <P1 列表/P2 表单/P3 详情/P4 看板/…> | <页头 → 筛选 → 内容 → 操作> | <lg 几列→sm 几列> | <文档滚动/内容区滚动/局部滚动> | <主按钮/操作条/无> | <加载/空/错误/无权限各放哪> |

## 4. 页面布局详图（按复杂度选做）
<每页一张线框：ASCII 线框或截图，标区域 ID 与尺寸约束；复杂页（对战/编辑器/矩阵）必须有>
~~~text
┌──────────────────────────────┐
│ 页头：标题 + 主操作            │
├──────────────────────────────┤
│ 筛选条                          │
├──────────────────────────────┤
│ 内容区（列表/表单/画布）        │
│                                │
├──────────────────────────────┤
│ 操作条（sticky/fixed）          │
└──────────────────────────────┘
~~~

## 5. 验收锚点
<每页布局的验收要点：关键区域可见、断点折叠正确、唯一滚动容器、吸底不遮挡内容、四态不跳动；对应截图基准路径>

## 6. 联动义务
<改布局 → 本文 + 页面详设 + 前端实现 + 浏览器实看证据；动壳/滚动 → DESIGN.md 布局框架节；新增路由 → 页面设计.md 路由表 + 本文矩阵>
```
