## FRD 骨架（`docs/01-需求/`，与 PRD 配套；功能需求 SSOT）

> Steward 适配：每个 FR 的验收最终收敛到 `02-spec.md` 的 AC；FR↔FP 追溯无孤儿，由 Plan Critic / `validate-plan.mjs` 复核。

> 定位：把 PRD 的 FR 展开成**可直接建模、拆端点、写用例**的系统行为规格。**不写技术实现**——表结构 / 端点签名 / 框架选型归 02-架构与 03-契约。
> 追溯契约：每个 FR 至少一个 FP，每个 FP 回指唯一 FR；两侧孤儿必须为 0，或逐条挂 OP。合并例外：极小项目可在 PRD 内保留「功能点级规格」节，但须声明合并理由。
